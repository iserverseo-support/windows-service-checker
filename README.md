# Windows Service Checker

A lightweight Windows command-line utility written in Go for checking Windows service statuses.

## Features

- Check one or multiple Windows services.
- Detect running and stopped services.
- Identify unavailable services.
- Return meaningful exit codes.
- Designed for Windows administrators.

## Usage

```powershell
windows-service-checker.exe <service-name>
